📊 CSAT Analytics Capstone Project

## 📌 Project Overview
This project focuses on analyzing Customer Satisfaction (CSAT) data to uncover key trends, service performance metrics, and areas for improvement in customer experience.

## 🛠️ Tools & Technologies Used
* **Power BI:** Data modeling, DAX calculations, and interactive dashboard creation
* **Excel / SQL:** Data cleaning, transformation, and exploratory analysis

## 📈 Key Objectives & Insights
* Track overall CSAT scores across different channels, regions, and product categories.
* Identify key drivers behind customer satisfaction and dissatisfaction.
* Provide actionable recommendations to enhance customer support efficiency.
